# 👨‍💻 Meu Portfólio

Bem-vindo ao meu portfólio! Aqui compartilho minha trajetória na área de desenvolvimento de software, minhas principais tecnologias e projetos desenvolvidos durante minha formação acadêmica e experiência profissional. Meu objetivo é demonstrar como aplico a tecnologia para desenvolver soluções, automatizar processos e resolver problemas reais.

---

## 🧑 Sobre Mim

Sou estudante de Desenvolvimento de Software Multiplataforma na FATEC Osasco e atuo como Desenvolvedor Júnior na área de Gestão de Abastecimento, trabalhando com Java 17, Spring Boot e Angular. Anteriormente, atuei em Data Analytics, desenvolvendo automações e aplicações para otimização de processos internos. Tenho maior afinidade com desenvolvimento back-end, especialmente na criação de APIs REST, integração de sistemas e implementação de regras de negócio. Busco constantemente aprimorar meus conhecimentos e aplicar boas práticas de desenvolvimento em projetos profissionais e pessoais.

---

## 💻 Tecnologias

Algumas das tecnologias e ferramentas com as quais trabalho:

- **Back-end:** Python (FastAPI, Django), Java (Spring Boot), APIs REST
- **Front-end:** React, Angular, JavaScript, TypeScript, HTML e CSS
- **Banco de Dados:** PostgreSQL, MySQL, SQL Server, SQLite, MongoDB e Firestore
- **Automação e Dados:** Pandas, Selenium, PyAutoGUI e Streamlit
- **Infraestrutura:** Docker, Linux, Google Cloud Platform (GCP), Render e Vercel
- **Ferramentas:** Git, GitHub, GitLab e DBeaver
- **Metodologias e Práticas:** Scrum, Kanban, SOLID, MVC e Design Patterns

## 🚀 Projetos

Neste portfólio você encontrará projetos acadêmicos, pessoais e profissionais, envolvendo diferentes tecnologias e desafios de desenvolvimento:

- **GymControl:** Sistema Full Stack para gerenciamento de academias, com controle de alunos, mensalidades, equipamentos e indicadores, desenvolvido com React, FastAPI e PostgreSQL.
- **Hands:** Marketplace Full Stack que conecta clientes a prestadores de serviços, com busca por localização, avaliações e painel administrativo, desenvolvido com React, FastAPI e MongoDB.
- **Supplier Automation:** Aplicação para automatização de processos de abertura de chamados, utilizando Python, Pandas, Selenium, PyAutoGUI e Streamlit.
- **APIs REST:** Desenvolvimento de serviços e integrações utilizando Python, FastAPI e Java com Spring Boot.
- **Outros projetos:** Aplicações web, automações e soluções envolvendo bancos de dados relacionais e NoSQL.
